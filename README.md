# בוט הורדת YouTube לטלגרם

בוט טלגרם בעברית שמקבל שם של שיר, קישור לסרטון או קישור לפלייליסט ושולח את הקובץ בחזרה.

- ברירת מחדל: MP3 באיכות 192kbps
- `/video`, `/video720`: וידאו עד 720p
- `/video360`: וידאו עד 360p
- פלייליסט: עד 20 פריטים ברצף
- מגבלת אורך: 20 דקות לפריט
- מגבלת גודל: 49MB לפריט

## פריסה ב-Render

ה-Blueprint נמצא ב-`render.yaml`. נדרשים `TELEGRAM_BOT_TOKEN` ו-`YT_REFRESH_TOKEN`. אחרי הפריסה יש לקרוא פעם אחת ל-`POST /setup-webhook` עם `Authorization: Bearer <WEBHOOK_SECRET>`.

הפרויקט מיועד ל-Render Free בלבד. מערכת הקבצים זמנית ואין שמירה של קבצים לאחר השליחה.
